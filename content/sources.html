참고 자료 · 표기 안내

추천 병과와 편성은 육성 방향을 정하기 위한 참고입니다. 실제 성능은 난이도·진행 구간·숙련도·장비에 따라 달라집니다. 게임에서 표시되는 조건과 전투 예측을 우선 확인하세요.

용어와 이미지

지역 복구는 파손된 도시·역·신전의 기능을 되살리는 일입니다. 복구 소재를 준비해 해당 지역에서 진행합니다. 제도 시설 재건은 거점의 훈련·식사 시설을 다시 여는 일로, 지역 복구용 소재와 재건 자재는 다릅니다.

캐릭터 이름은 한국어 플레이 자료를 우선하며, 일부 이름·병과·장비는 일본어를 함께 표기합니다. 「コウカ」는 홍화, 「イシュマール」는 이름을 설정할 수 있는 구세주를 가리킵니다. 사도(シドー)와 바테스(ウァテス)는 한국어 표기로 표시합니다.

직업 아이콘은 Game8 병과 목록의 해당 일본어 이름과 대조했습니다. 카드 색상은 아이콘 원본 배경을 기준으로 맞췄습니다. 색상만으로 무기·기술 사용 가능 여부를 판단하지 말고 전직 조건을 함께 확인하세요.

외형이 달라지는 44명은 3부 컷을 사용합니다. 외형이 같은 18명은 기본 컷이며, 클라프카도 기본 컷으로 표시합니다. 클라프카의 3부 전용 외형은 확인 중입니다.

평가 기준과 자료 범위
  • 1부 등급은 1부의 육성 우선순위에 관한 참고 평가입니다. 같은 등급 안의 순서는 우열이 아닙니다.
  • 3부 도감의 종합 평가는 참고 자료의 인물별 평가입니다. 3부만을 대상으로 한 확정 순위는 아닙니다. 핵심 후보는 역할별 편성에 유용한 인물입니다.
  • 직업 후보와 요구 기술은 일본어 개별 공략을 참고합니다. 일부 한국어 병과·장비명과 전 캐릭터의 최적 세팅, 동물별 전체 위치·먹이표는 추가 확인이 필요합니다.
  • 칼날 울림·군단병·공연·블레이즈 아츠·전투 기술은 한국닌텐도 안내를 참고합니다. 지역 복구·제도 재건 표기는 국내 공략 자료와 대조했습니다.
  • 개인 플레이 기록은 해당 구간·난이도에서의 사례입니다. 모든 조건에 동일하게 적용되는 결과는 아닙니다.

3부 탈것·복구 재료·편성 추가 자료와 이미지

탈것과 재료 그림은 게임의 계열·분류 아이콘이며 같은 계열이 그림을 공유합니다. 탐색·재배 화면은 일본어판 예시입니다. 복구 요구량이 상충하면 큰 값을 준비량으로 표시하며, 실제 납품량은 게임 메뉴를 우선합니다. 한국어명 미확인 항목은 원문·임시 대조 표기를 구분합니다.

한국어 지역·채집물 명칭 대조 자료

한국어 도감이 게임 화면 근거를 명시한 명칭과 국내 직접 플레이 기록을 대조했습니다. 모든 원본 게임 화면을 새로 직접 확인한 것은 아닙니다. 자료 자체가 임시 표기로 분류하거나 한국어 이름이 서로 다른 항목은 ‘한국판 표기 확인 중’으로 표시합니다. 출처별 이름·상태·이전 이름은 별도의 명칭 데이터로 관리합니다.
